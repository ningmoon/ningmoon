## 👨‍💻 About Me

I am an automotive control engineer focused on **vehicle dynamics control, semi-active suspension, embedded control systems, and model-based development**.

My work spans the complete engineering chain:

**Control Strategy → Model → Embedded Software → Vehicle → Measurement → Evaluation → Calibration**

I am particularly interested in building engineering systems that are **measurable, testable, traceable, and reproducible**, and in using AI to improve real engineering workflows rather than treating it only as a coding assistant.

## 🔁 Engineering Loop

Most of my projects revolve around one engineering loop:

```text
┌─────────┐    ┌───────────┐    ┌─────────┐    ┌─────────┐
│  Model  │ →  │ Algorithm │ →  │   ECU   │ →  │ Vehicle │
└─────────┘    └───────────┘    └─────────┘    └────┬────┘
      ▲                                             │
      │                                             ▼
┌───────────┐    ┌────────────┐    ┌─────────────────────┐
│ Iteration │ ←  │Calibration │ ←  │ Measurement & Eval. │
└───────────┘    └────────────┘    └─────────────────────┘
```
